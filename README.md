# Dionix Softowrks website

Acesta este siteul meu cu docker-compose, react, si primul fastapi pe care l-am facut. 
Implementat trimis raspunsuri formular in backend la fastapi, iar de acolo trimis raspunsul pe telegram.

## Trading app (MT5)

`trading-backend/` și `trading-frontend/` sunt o aplicație separată de
tranzacționare pe conturi MetaTrader 5: grafic interactiv (click pe grafic
pentru a seta Stop Loss / Take Profit), calcul automat al lotului pe baza
unui procent din balanță, buy/sell rapid, și suport pentru mai multe conturi
MT5 tranzacționate individual sau simultan. Vezi `trading-backend/README.md`
pentru detalii de configurare (rulează cu MT5 real doar pe Windows; are un
mod simulat pentru dezvoltare pe orice OS).
